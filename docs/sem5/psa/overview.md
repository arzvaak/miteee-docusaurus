# Power System Analysis

These notes cover all 60 lectures of the NPTEL course **Power System Analysis** by Prof. Debapriya Das, IIT Kharagpur. The official 1,165-page course book was processed with Mistral OCR 4 so that handwritten equations, circuit diagrams, numerical iterations, examples, exercises, and questions could be recovered alongside the printed transcript. DeepSeek V4 Flash was then used to draft structured study notes from the OCR evidence.

The source PDF has an unusual physical order (`1, 10...19, 2, 20...`). The local pipeline corrects that ordering before OCR and rebuilds every week as five consecutive numeric lectures. The 12 notes below therefore cover Lectures 1–60 in their intended sequence.

## Study approach

- Read the lecture sections in order and reproduce every derivation independently.
- Use the source-visual walkthroughs for network diagrams, phasors, iteration tables, sequence networks, and stability curves.
- Work through the examples without looking at the solution, then compare units, signs, assumptions, and numerical sanity checks.
- Finish each week with the quick-revision sheet and 18-question practice quiz.
