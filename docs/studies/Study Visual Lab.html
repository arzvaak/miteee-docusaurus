Confidence is a property of the procedure

Each row is a fresh interval from a simulated normal sample. The green ones cover the fixed true mean (vertical line). The red ones miss it. Increasing sample size narrows intervals; increasing confidence widens them.

CRA 4411: intervals chapter, class Q7, mock 1 Q4/Q13/Q21. Toy model uses known population σ = 10 and normal critical values.

Watch each observation take one turn in validation

Each row shows one fold. Blue cells train the model and amber cells validate it. Every column is amber exactly once.

Training error is not the model selection target

A toy error model shows training error falling as complexity rises, while validation error eventually rises. Move complexity; choose near the minimum of validation error.
