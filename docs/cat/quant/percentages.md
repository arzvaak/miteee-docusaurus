## 2. Foundations

### 2.1 Definition

> A fraction with denominator 100 is called a **per cent**. (p. 293)

- **Per cent** = Latin "percentum" = "per hundred" or "hundredths"
- Denoted by symbol **%**
- Since per cent is a form of fraction, we can express per cent as fractions (or decimals) and *vice-versa* (p. 293)

**Core importance:** "backbone of calculations either involved in commercial arithmetic or in real life" (p. 293)

**CAT frequency:** "On an average two problems i.e., nearly 4-5 % problems in QA only, are being asked in CAT every year" (p. 293)

---

### 2.2 Conversion Rules

| Conversion | Rule | Example |
|-----------|------|---------|
| Fraction → % | Multiply by 100, add % | 3/4 × 100 = 75% |
| % → Fraction | Replace % with 1/100, simplify | 20% = 20/100 = 1/5 |
| % → Ratio | Convert to fraction, then ratio | 38% = 19:50 |
| Ratio → % | Convert to fraction, multiply by 100 | 2:3 = 66.66% |
| % → Decimal | Remove %, move decimal 2 places left | 36% = 0.36 |
| Decimal → % | Move decimal 2 places right, add % | 0.35 = 35% |

**Worked examples (p. 293–294):**

- $5\frac{1}{8}\% = \frac{41}{8 \times 100} = \frac{41}{800}$
- $155\% = \frac{155}{100} = \frac{31}{20} = 1\frac{11}{20}$
- $66.66\% = 66\frac{2}{3}\% = \frac{200}{3 \times 100} = \frac{2}{3} = 2:3$
- $17\frac{1}{5}\% = 17.2\% = 0.172$
- $8.12 = 812\%$
- $0.018 = 1.8\%$

## 3. Percentage of a Quantity

### Formula

$$x\% \text{ of } y = \frac{x}{100} \times y$$

### Worked Examples (p. 295)

**Exp. 1:** 42% of 1000 = 42/100 × 1000 = **420**

**Exp. 2:** 85% of 400 = 85/100 × 400 = **340**

**Exp. 3:** 16⅔% of 360 trees are mango trees.
- Mango trees = (50/3)/100 × 360 = **60**
- Other trees = 360 − 60 = **300**
- **Alternative:** Other trees = (100 − 16⅔)% = 83⅓% of 360 = **300**

### CAT Tip (p. 295)
> "All the problems mentioned in the exercise must be done using fractions instead of percentage, in order to make the calculation simple and handy."

**Example:** 16.66% = 1/6, so 16.66% of 360 = 360/6 = 60. Much faster!

## 4. Expressing One Quantity as a Percentage of Another

### Rule (p. 297)
> "To find what per cent the first number is of second number, we divide the first number by the second number and multiply the result by 100."

$$\text{Percentage} = \frac{\text{First quantity}}{\text{Second quantity}} \times 100\%$$

### Worked Examples (p. 297)

**Exp. 1:** What per cent is 3 of 20?
$$3/20 \times 100 = 15\%$$

**Exp. 2:** Ravi scored 325 out of 400.
$$325/400 \times 100 = 81.25\%$$

**Exp. 3:** 150 workers, 18 absent.
- Present = 150 − 18 = 132
- Percentage present = 132/150 × 100 = **88%**

**Exp. 4:** Kurla 480/600 vs Birla 560/800.
- Kurla: 480/600 × 100 = 80%
- Birla: 560/800 × 100 = 70%
- **Kurla performed better** despite lower absolute marks

**Key insight:** Always compare percentages, not absolute values, when bases differ.

## 5. Percentage Change

### 5.1 Formulas (p. 298)

**Percentage increase:**
$$\left( \frac{\text{increased value} - \text{original value}}{\text{original value}} \times 100 \right) \%$$

**Percentage decrease:**
$$\left( \frac{\text{original value} - \text{decreased value}}{\text{original value}} \times 100 \right) \%$$

### Worked Examples (p. 298)

**Exp. 1:** Height increased from 110 cm to 120 cm.
$$\frac{120-110}{110} \times 100 = \frac{10}{110} \times 100 = 9.09\%$$

**Alternative:** 12/11 = 109.09%, so increase = 109.09 − 100 = 9.09%

**Exp. 2:** Expenses decreased from ₹8000 by ₹1000.
$$\frac{1000}{8000} \times 100 = 12.5\%$$

**Exp. 3:** Raja ₹9,000, Rani ₹10,000.
- Rani as % of Raja: 10000/9000 × 100 = **111.11%**
- Raja as % of Rani: 9000/10000 × 100 = **90%**

**Fraction shortcut:** 10/9 = 9/9 + 1/9 = 100% + 11.11% = 111.11%

---

### 5.2 Percentage Point Change (p. 298)

> "Percentage point change is the difference between two percentage values."

**Example (p. 298):** Abhijeet: ₹10,000 → ₹12,000 (20% increase); Sonu: ₹8,000 → ₹10,000 (25% increase)
- Percentage point change = 25 − 20 = **5 percentage points**
- Sonu's increase is (25−20)/20 × 100 = **25% greater** than Abhijeet's

**Trap alert:** Percentage point change ≠ percentage change. 5 percentage points is a 25% relative difference.

---

### 5.3 Getting Back Original Value After Increase (pp. 298–299)

**Formula:** If value p is increased by x%, decrease resultant by:
$$\left( \frac{x}{x + 100} \times 100 \right) \%$$

**Fraction form:** If increased by n/d, decrease by n/(d+n)

**Derivation (p. 299):**
- Original p → increased value = p(100+x)/100
- Percentage decrease = [p(100+x)/100 − p] / [p(100+x)/100] × 100 = (x/(100+x)) × 100%

**Worked Examples (p. 299):**

**Exp. 1:** Salary ₹100 → ₹125 → ₹100
- Increase: (125−100)/100 × 100 = **25%**
- Decrease: (125−100)/125 × 100 = **20%**

> "There is same absolute change but percentage change is different due to different denominator (i.e., base change). So the base change is as much important as the numerator or absolute change in quantity." (p. 299)

**Exp. 2:** Shyam's age is 25% greater than Ravi (20 years). How much % is Ravi less than Shyam?
- Using formula: x = 25, decrease = 25/125 × 100 = **20%**
- Using fraction: increase = 1/4, decrease = 1/(4+1) = 1/5 → **20%**

**Exp. 3:** Gautam has 33.33% more pencils than Rahul.
- 33.33% = 1/3, so decrease = 1/(3+1) = 1/4 → **25% less**

**Exp. 4:** Amitabh's height 50% greater than Amir.
- 50% = 1/2, decrease = 1/(2+1) = 1/3 → **33.33% less**

**Visual understanding (p. 299):** See `images/page-0299-img-0.jpg` (pencil comparison) and `images/page-0299-img-1.jpg` (height comparison).

**Concept example (p. 299):** A has 10 apples, B has 20 apples
- B has 100% more apples than A
- A has 50% less apples than B

> "Remember the percentage change graphic is almost 70-80% better in giving quick and simple results. So instead of using the percentage formula, use the percentage change graphic method. For this you are just required to know the percentage fraction conversion table." (p. 299)

---

### 5.4 Getting Back Original Value After Decrease (p. 300)

**Formula:** If value P is decreased by x%, increase resultant by:
$$\left( \frac{x}{100 - x} \times 100 \right) \%$$

**Fraction form:** If decreased by n/d, increase by n/(d−n)

**Worked Examples (p. 300):**

**Exp. 5:** Salary reduced by 20%, then restored.
- Let initial = ₹100
- 100 → 80 (after 20% decrease)
- Increase needed = 20/80 × 100 = **25%**
- Using formula: x = 20, increase = 20/(100−20) × 100 = **25%**

**Exp. 6:** Kajol wears saree 16.66% less than actual length.
- 16.66% = 1/6, increase = 1/(6−1) = 1/5 → **20% greater**

---

### 5.5 Important Notes (p. 300)

1. If X increased by p% to Y, then Y decreased to X by q% → **p is always greater than q** (for positive values)
2. If X decreased by p% to Y, then Y increased to X by q% → **p is always less than q**
3. Successive increases by p%, q%, r% → order doesn't matter (result same)
4. Successive decreases by p%, q%, r% → order doesn't matter (result same)
5. Mixed increase/decrease: A increased by p%, then q%, then reduced by r% → same as A decreased by r%, then increased by q%, then p%

**Worked Examples (p. 300):**

**Exp. 7:** ₹200 increased by 20%, then by 25%.
- 200 → 240 → 300
- Required % = (300−200)/200 × 100 = **50%**

**Exp. 8:** B's age is 50% greater than A. C's age is 20% less than B.
- A = 100, B = 150, C = 120
- C is 20/100 × 100 = **20% greater** than A

---

### 5.6 Reversing the Change by Same Percentage (pp. 300–301)

**Key Rule:**
> "If the value of a number is first increased by x% and then decreased by x%, the net change is always a decrease (or loss) in original value. That is, % loss = (x/10)²%"

> "If the value of a number is first decreased by x% and then the resultant value is increased by x%, the net change is always a decrease (or loss) in the original value. That is % loss = (x/10)²"

**Worked Examples (pp. 300–301):**

**Exp. 1:** Price increased 15%, then decreased 15%.
- 100 → 115 → 97.75 (loss of 2.25%)
- Using formula: loss% = (15/10)² = **2.25%**
- "There is always a loss."

**Exp. 2:** Length +20%, breadth −10%.
- 1 × 1 = 1 → 1.2 × 0.9 = 1.08
- **8% increase** in area

**Exp. 3:** A's salary 20% lower than B. C's salary 56.25% greater than A.
- Let B = 100
- A = 80, C = 125
- Required = 25/125 × 100 = **20%**

## 6. Product Constancy (pp. 301–302)

### Definition (p. 301)
> "It is the same as we know the inverse proportion in the chapter of Ratio, Proportion and Variation."

**Example (p. 301):**
- Rate × No. of pencils = Price
- 1.25 × 16 = 20, 1.00 × 20 = 20
- Product (20) is constant in both cases

### Examples of Product Constancy (p. 301)
- (i) speed × time = distance
- (ii) rate × time = cost
- (iii) efficiency × time = work
- (iv) length × breadth = area
- (v) average × no. of elements = total value
- (vi) rate × quantity = price (or expenditure)

### Conditions (p. 301)

**Condition 1:** When one factor increased by p%, other factor decreased by:
$$\left( \frac{p}{100 + p} \times 100 \right) \%$$

**Fraction form:** One factor increased by n/d → other decreased by n/(d+n)

**Condition 2:** When one factor decreased by p%, other factor increased by:
$$\left( \frac{p}{100 - p} \times 100 \right) \%$$

**Fraction form:** One factor decreased by n/d → other increased by n/(d−n)

### Worked Examples (pp. 301–302)

**Exp. 1:** Price raised 20%, by how much % reduce consumption to keep expenditure same?
- 1 × 1 = 1 → 1.2 × x = 1 → x = 0.833
- Decrease = **16.66%**
- Alternative: +20% = +1/5 → −16.66% = −1/6

**Exp. 2:** Price of petrol falls 20%.
- Decrease 20% = 1/5 → increase 1/4 = **25%** [since n/d → n/(d−n)]

**Exp. 3:** 50% increase in rice price, purchased 5kg less with ₹60.
- Increase 50% = 1/2 → decrease 1/3 = 33.33%
- 33.33% = 5kg → initial = 15kg
- Initial price = 60/15 = ₹4
- Final price = 60/10 = **₹6**

**Exp. 4:** Length decreased 33.33%.
- 33.33% = 1/3 → increase 1/(3−1) = 1/2 = **50%**

## 7. Difference Between 'by' and 'to' (p. 302)

> "There is a clear difference between 'by' and 'to'. For example, the income is reduced by 40% it means the new income is 60% of the original and the income is reduced to 40% means the new income is 40% of the original value. Thus 'by' represents difference and 'to' represents final value." (p. 302)

**Examples (p. 302):**
- Income increased **by** 20% → new income = 120% of original
- Income increased **to** 120% → new income = 120% of original

---

## 8. Difference Between Decreased Value and Decrease in Value (pp. 302–303)

> "There is a huge difference between 'decreased value' and 'decrease in value' similarly, there is a huge between 'increased value' and 'increase in value'." (p. 302)

**Example (p. 302):**
- Initial = 70, Final = 90
- Increased value = 90
- Increase in value = 20
- % increase = (90−70)/70 × 100 = 28.57%

**Formulas (p. 302):**
1. If increase of x/y in value P → increased value = P(1 + x/y)
2. If decrease of x/y in value P → decreased value = P(1 − x/y)

**Worked Examples (p. 303):**

**Exp. 1:** Nishith is 20 years old. Later his age increases by 50% of himself.
- 20(1 + 1/2) = **30 years**

**Exp. 2:** Salary in Infosys is 20% less than Microsoft (₹80,000).
- 20% = 1/5
- New salary = 80,000(1 − 1/5) = 80,000 × 4/5 = **₹64,000**

> "Remember this type of problems can also be solved exactly through percentages. As 80,000 × 0.8 (100 − 20 = 80%) = 64,000. But the technique given above is not less important. Some where it becomes very necessary to solve through fractions." (p. 303)

**Exp. 3:** Which is greatest: 3/4, 7/8, 16/19, 13/15?
- 3/4 = 75%
- 7/8 = 87.5%
- 16/19 = 84.21%
- 13/15 = 86.66%
- **7/8 is the greatest**

## 9. Problems Based on Population (p. 303)

### Formulas (p. 303)

**Population increase:**
$$\text{Population after } n \text{ years} = P\left(1 + \frac{r}{100}\right)^n$$

**Population decrease:**
$$\text{Population after } n \text{ years} = P\left(1 - \frac{r}{100}\right)^n$$

### Worked Examples (p. 303)

**Exp. 1:** Annual increase 20%, present population 10,000. Population after 3 years?
$$10{,}000\left(1 + \frac{20}{100}\right)^3 = 10{,}000\left(\frac{6}{5}\right)^3 = 10{,}000 \times 1.2^3 = \textbf{17,280}$$

**Exp. 2:** Population increases 10% in year 1, decreases 10% in year 2, repeats for 4 years. Present = 20,000.
$$20{,}000(1.1)(0.9)(1.1)(0.9) = 20{,}000 \times 1.21 \times 0.81 = \textbf{19,602}$$

## 10. Additional Solved Examples (p. 302)

**Exp. 1:** Candidate got 57% valid votes, won by 420 votes.
- Winner: 57%, Loser: 43%
- Difference: 14% = 420
- Total valid votes = 420/0.14 = **3000**

**Exp. 2:** Production decreased 60%. By what % should working hours increase to restore production?
- Manpower × Working hours = Production
- (−60%) = 3/5 → increase 3/(5−3) = 3/2 = **+150%**
- "The new working hours will be 2.5 times (not 1.5 times) of the original time."

**Exp. 3:** Two numbers are 25% and 40% less than a third. Second is what % of first?
- Let C = 100
- A = 75, B = 60
- 60/75 × 100 = **80%**

**Exp. 4:** Person gives 10% to wife, 10% of remaining to hospital, 10% of remaining to PM Relief Fund. Left with ₹7290.
- Remaining = x × 0.9 × 0.9 × 0.9 = 0.729x = 7290
- x = **₹10,000**

**Exp. 5:** Customer bought 10%, then 20% of remaining, then 25% of remaining. Left with 270 chocolates.
- n × 0.9 × 0.8 × 0.75 = 270
- n = 270 × 10000/(9×8×75) = **500**

> "These type of problems (see example no. 4 and 5) can be solved with a great convenience if we solve in reverse order, with the aid of given choices." (p. 302)

## 11. Fast CAT Methods

### Method 1: Fraction Substitution

Replace percentages with equivalent fractions for instant calculation.

**Example:** 16.66% of 360 = 360/6 = 60 (instead of 0.1666 × 360)

### Method 2: Percentage Change Graphic

Instead of formulas, use the fraction method:
- Increase by 1/4 → decrease by 1/5 to get back
- Decrease by 1/5 → increase by 1/4 to get back

### Method 3: Option Testing (p. 302)

For problems like Exp. 4 and 5 above, work backwards from options.

**Example:** Verify 500 × 0.9 = 450 → 450 × 0.8 = 360 → 360 × 0.75 = 270 ✓

### Method 4: Table Method (p. 296)

For problems with multiple categories:

| Female | Male | Total |
|--------|------|-------|
| 44% | 56% | 100% |
| | 42 | |

- 56% = 42, so 1% = 42/56
- 100% = 100 × 42/56 = **75 students**

### Method 5: Reverse Calculation

To find original value from final value after successive changes:
$$\text{Original} = \frac{\text{Final}}{(1 + r_1/100)(1 + r_2/100)...}$$

## 12. Worked Examples: Easy to Advanced

### Easy Level

**Example 1:** Find 37.5% of 300.
- 37.5% = 3/8
- 3/8 × 300 = **112.5**

**Example 2:** What per cent is 36 kg of 150 kg?
- 36/150 × 100 = **24%**

**Example 3:** Price increased from ₹16.50 to ₹41.25.
- Increase = 41.25 − 16.50 = 24.75
- % increase = 24.75/16.50 × 100 = **150%**

---

### Medium Level

**Example 4:** A number increased by 37.5% gives 99. Find the number.
- 37.5% = 3/8
- Number × (1 + 3/8) = 99
- Number × 11/8 = 99
- Number = 99 × 8/11 = **72**

**Example 5:** When 40% of a number is added to 42, result is the number itself.
- Let number = x
- 0.4x + 42 = x
- 0.6x = 42
- x = **70**

**Example 6:** 52% failed Science, 42% failed Mathematics, 17% failed both.
- Failed at least one = 52 + 42 − 17 = 77%
- Passed both = 100 − 77 = **23%**

---

### Advanced Level

**Example 7:** 60% female employees. 50% of male employees computer literate. 62% total employees computer literate out of 1600. Female employees who are computer literate?

**Solution:**
- Total = 1600
- Female = 60% = 960, Male = 40% = 640
- Computer literate total = 62% of 1600 = 992
- Male computer literate = 50% of 640 = 320
- Female computer literate = 992 − 320 = **672**

**Example 8:** Car depreciates 25% first year, 20% second, 15% third. Final price if present cost ₹10,00,000?

**Solution:**
- 10,00,000 × 0.75 × 0.80 × 0.85
- = 10,00,000 × 0.51
- = **₹5,10,000**

**Example 9:** A's salary is half of B. A got 50% raise, B got 25% raise. % increase in combined salaries?

**Solution:**
- Let B = 100, A = 50
- Combined = 150
- New: A = 75, B = 125, Combined = 200
- Increase = 50/150 × 100 = **33.33%**

**Example 10:** Rectangle area 60 cm². Length decreased 20%, breadth increased 25%.

**Solution:**
- 1 × 1 = 1 → 0.8 × 1.25 = 1.0
- Area unchanged → **0% error** (option d: none of these)

## 13. Decision Rules

| Situation | Rule |
|-----------|------|
| "What % is X of Y?" | (X/Y) × 100 |
| "X is what % greater than Y?" | (X−Y)/Y × 100 |
| "X is what % less than Y?" | (Y−X)/Y × 100 |
| "X is what % of Y?" | (X/Y) × 100 |
| "Increase by x%, then decrease by x%" | Always loss = (x/10)²% |
| "Get back after x% increase" | Decrease by x/(100+x) × 100% |
| "Get back after x% decrease" | Increase by x/(100−x) × 100% |
| "Price up, expenditure constant" | Consumption down by p/(100+p) × 100% |
| "Price down, expenditure constant" | Consumption up by p/(100−p) × 100% |
| "Population grows r% for n years" | P(1 + r/100)ⁿ |
| "Population declines r% for n years" | P(1 − r/100)ⁿ |
| "Increased by n/d" | Decrease by n/(d+n) to get back |
| "Decreased by n/d" | Increase by n/(d−n) to get back |

## 14. Common Traps

### Trap 1: Base Change
> "There is same absolute change but percentage change is different due to different denominator (i.e., base change)." (p. 299)

**Example:** ₹100 → ₹125 → ₹100
- Increase = 25%, Decrease = 20% (not 25%!)

### Trap 2: 'by' vs 'to'
- Reduced **by** 40% → new = 60% of original
- Reduced **to** 40% → new = 40% of original

### Trap 3: Decreased Value vs Decrease in Value
- Decreased value = final value
- Decrease in value = original − final

### Trap 4: Percentage Point vs Percentage Change
- 20% → 25% is 5 percentage points, but 25% relative change

### Trap 5: Same % Increase and Decrease
- Always a loss, never break-even
- Loss = (x/10)²%

### Trap 6: Market Share Combination (Q23, Level 03)
- Market share percentages alone don't determine combined market leadership without total market sizes

### Trap 7: Category-wise Data (Q32, Level 03)
- Tariff table is sector/region-wise, not category-wise — cannot compute category tariffs

### Trap 8: Absolute vs Percentage Increase (Q50, Level 03)
- Least increase in amount ≠ least percentage increase — compare absolute values

### Trap 9: Combining Markets (Q21, Level 03)
- When combining markets, use total values, not percentages directly

### Trap 10: 99.99% = 100%
- 9/9 = 99.99% but 9/9 = 100% (p. 295)

## 15. Timed Strategy

### Suggested Time Allocation (for 2-minute CAT problems)

| Step | Time | Action |
|------|------|--------|
| 1 | 10 sec | Read problem, identify type (change, product constancy, population, etc.) |
| 2 | 20 sec | Convert percentages to fractions |
| 3 | 60 sec | Apply the appropriate formula/method |
| 4 | 20 sec | Verify with option or reverse calculation |
| 5 | 10 sec | Mark answer |

### Speed Tips

1. **Memorize the conversion table** — this is non-negotiable
2. **Use fraction substitution** — 16.66% = 1/6, 14.28% = 1/7, etc.
3. **For successive changes**, multiply factors directly: 1.2 × 0.9 = 1.08
4. **For reverse problems**, work backwards from options
5. **For product constancy**, use the fraction shortcut: n/d → n/(d±n)

### When to Skip

- If a problem requires more than 3 steps of calculation
- If the data seems insufficient (check for hidden assumptions)
- If you're spending more than 2 minutes — mark and move on
